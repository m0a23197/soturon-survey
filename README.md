# 卒業研究アンケート

## 現在の仕様
- 回答者情報：年齢、CG制作経験、CG制作頻度、3DCG作品を見る頻度
- 比較評価18問
- 大きな質問の順番：固定
- 各大項目内：教室・神社を交互、開始シーンは回答者ごとにランダム、各シーン内の順番はランダム
- 汚れ量・情報量比較：左右を回答者ごとにランダム化
- 汚れなし比較：左=汚れあり、右=汚れなしを固定
- 最後の「最もリアル」：5枚の並びをランダム化
- 前の質問に戻るボタンなし
- 画像クリックで同じページ上で拡大
- 画像の右クリック・ドラッグを無効化
- 次の質問の画像を先読み
- 回答はGoogle Apps Script経由でGoogleスプレッドシートへ保存

## GitHub公開時
このフォルダを公開用リポジトリにアップロードしてください。
`Code.gs` はGitHubにはアップロードせず、Google Apps Script側に使用してください。

## Apps Script
`Code.gs` の `SHEET_ID` を回答保存先スプレッドシートのIDに変更し、Webアプリとしてデプロイしてください。


## 今回の更新
- CG制作経験が「ある」の場合のみ、CG制作頻度と3DCG作品を見る頻度を表示・回答する仕様。
- 比較評価の選択肢を横並び表示。
- 「汚れなしとの比較」は左=汚れなし、右=汚れありに変更。


## 表示設定
- 各質問のカテゴリ名（汚れなしとの比較、汚れ量の比較、情報量の比較など）は回答画面の上部に表示しません。
- 次の質問の画像は回答中にバックグラウンドで先読みします。
