# 卒業研究アンケート

完全新規構成。高画質1920×1080画像10枚を使用。

主な仕様：
- 年齢 → 3DCG作品を見る頻度（全員） → CG制作経験 → 制作頻度（経験ありのみ）
- 汚れなし比較8問
- 汚れ量比較4問
- 情報量比較4問
- 再テスト5問（汚れ量・情報量の8問から回答者ごとにランダム抽選、初回と左右反転）
- 最終ランキング2問
- 大項目開始前に説明ページ
- 教室・神社は各大項目内で交互、開始シーンはランダム
- 汚れ量・情報量比較は左右ランダム
- 汚れなし比較は左=汚れなし、右=汚れあり
- ランキング初期配置は「汚れなし→中・低→中・高→強・低→強・高」
- 前の質問へ戻れない
- 画像は表示中に次の質問をバックグラウンド先読み
- 読み込み失敗時は表示画像だけ最大3回再試行
- 画像は右クリック・ドラッグを抑止
- 回答はGoogle Apps Scriptへ送信
